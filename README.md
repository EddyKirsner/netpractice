# NetPractice

> Networking exercises on **IPv4 addressing, subnetting and routing**: ten small network diagrams to configure (hosts, switches, routers, internet gateway) so that every required host can reach the others.

## Concepts practised

- IPv4 addresses, network and broadcast addresses
- Subnet masks and **CIDR** notation (`/24`, `/30`, ...), splitting a range into non-overlapping subnets
- Private vs public address ranges (RFC 1918)
- Switches (same subnet, layer 2) vs routers (between subnets, layer 3)
- **Routing tables**: default routes (`0.0.0.0/0`), next hop, routes to the internet
- Debugging connectivity: finding the misconfigured interface, mask or route

## Content

`level1.json` to `level10.json` are the exported configurations for each level.
